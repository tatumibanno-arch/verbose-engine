# 転がしの1回の判断の手順（v5、スケジュールから呼ばれる）

決まりは notes/bets/rolling-rules.md の現行版。台帳は notes/bets/rolling-<今日>.md（「今日の厳選レース」の表と「記録」の表）。日付は JST の今日。

0. **紙上の日・時間帯の確認**: 台帳の先頭付近に「紙上のみ」と書いてあれば、その範囲は LINE を送らない。判断と買い目は同じように作り、記録表に【紙上】と書いて、紙上の残高（当たりは持ち越し、外れは1,000円）で進める。
1. `git pull --rebase --autostash`。運用者が会話で「止める」と言っていれば何もしないで終わり。
2. **前に LINE を出したレースの確定**: 記録表で結果が空の行があれば、boatrace.jp の raceresult（scripts/scrape_web.py の fetch）で結果を取り、払戻と確定の倍率を書く。まだ出ていなければ出るまで待つ（待っている間に締切を過ぎた候補は飛ばす）。
3. **残高**: 運用者が会話でそのレースに「入った／入ってない」を言っていればそれに従う。何も言っていなければ「入った」として計算し、記録表の「入った？」に「返事なし（入った扱い）」と書く。
   - 入って的中 → 払戻を持ち越し（次は +1 段目）。入って外れ → 1,000円から（1段目）。入っていない・見送り → 残高も段もそのまま。
   - 残高が10,000円以上 → 「10,000円達成」を LINE で送り、次は1,000円から。
4. **次の候補**: 厳選レースの表で、締切が今から8分以上先・45分以内のものを締切順に見る。
   - `ROLL_DATE=<今日> python scripts/analysis/roll_pre.py <jcd> <rno> 1-2-3` で展示と進入（まだなら締切10分前まで待つ）。**進入が枠番どおり（1-2-3-4-5-6）でなければ見送り**（スタ展の進入で判断。①が1コースでも、ほかの艇が動いていたら見送り）。
   - 締切の約10分前に `ROLL_DATE=<今日> ROLL_SHRINK=0.75 python scripts/analysis/roll_one.py <jcd> <rno> <残高> <倍率> 20` の3連単の行。倍率は2.0（残高5,000円以上は 10000÷残高、最低1.3）。モデル的中40%未満なら見送り。
   - 入れるものが見つかったら、そのレースで LINE を出して終わり（同じ回で2つは出さない。結果が出るまで残高が決まらないため）。見送ったレースは記録表に理由を1行。
5. **LINE**（notes/line/<今日>-roll3t-<締切HHMM>.md → コミット・プッシュ → live_alert.yml を ref main, inputs {mode: send, file: ...} で起動し成功を確認）: 【3連単 転がし】何段目・残高、前のレースの結果、レース・締切、展示の要点、買い目と金額・各目の今のオッズと払戻・25%下がった場合の最低払戻、モデル的中率とオッズから見た的中率、オッズの時刻、「入ったかどうか教えてください」、判断材料であって推奨ではない旨。この時間帯に入れるレースが無ければ LINE は送らない。
6. 記録表に追記してプッシュ。会話には1〜3行で報告。
