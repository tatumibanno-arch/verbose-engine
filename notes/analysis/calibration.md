# 1着確率と予想配当の補正（ウォークフォワード）

`scripts/analysis/calibrate.py`

## 0. 事前の宣言（結果を見る前に書いた）

- 補正のやり方（主に使う1本）
  - 単勝の1着確率 p: レース内 softmax の再校正 `s_i = a·log p_i + c·(log p_i)^2 + b_艇番`（7個のパラメータ）。各月 m は m より前の最大12か月（2024-05〜）で対数損失最小に当てる。比較用に isotonic（艇をまとめて単調回帰→レース内で合計1に直す）も出すが、候補の評価には使わない。
  - 単勝の予想配当 g: 当たった艇だけで `E[実配当 | 当たり] = g·exp(β·x)`、x = [1, log g, (log g)^2, 艇番, 確率順位] のポアソン回帰（平均を合わせる）。各月 m は m より前の最大12か月（g がある 2024-11〜）の当たりで学習。前の月の当たりが 3000 本に満たない月（2024-11）は補正なし。
  - 2連単: 確率 P2（3連単の確率を足したもの）を `s = a·log P2 + c·(log P2)^2 + b_1着艇 + b_2着艇` の softmax で再校正、配当 g2+ は単勝と同じ形のポアソン回帰（x = [1, log g, (log g)^2, 1着艇, 2着艇, 確率順位の帯]）。
- 候補（新しい系統。ここに書いたもの以外は試さない）
  - 単勝 補正EV: p_cal ≥ {0.20, 0.30} × EV_cal = p_cal·g_cal/100 ≥ {1.00, 1.05, 1.10} → **6通り**
  - 2連単 補正EV最大1点: P2_cal ≥ 0.05 の中で EV_cal 最大の1点、EV_cal ≥ {1.0, 1.1, 1.2} → **3通り**
  - 合計 **9通り**。比較用に、補正なしの tansho_ev_v1（p≥0.20・EV≥1.0）と 2連単 g2+ p≥5% k=1 EV≥1.2（multi_bet.md の候補）も同じ集計で出す（新しい候補には数えない）。
- 1本を選ぶ手順: 系統ごとに、発見用（2024-11〜2025-10）で的中 100 本以上のうち発見用の通算回収率が最良の1本を選び、その1本の検証用（2025-11〜2026-10）の成績を見る。検証用で他の組み合わせが良くても、それは後知恵として扱う。
