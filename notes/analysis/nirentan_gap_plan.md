# 2連単と3連単のずれ（確定オッズ）の検証計画 — 2026-11-04、データを見る前に固定

データ: 2025-11〜2026-10 の確定オッズ（2連単は backfill_web で取り込み、3連単は既存）と2連単の払戻。
発見用 = 2025-11〜2026-04、検証用 = 2026-05〜10。月次回収率・勝ち月・最悪月・1日の点数を出す。

ずれ = 3連単オッズから出した「a-b の順で1・2着」の確率 ÷ 2連単オッズから出した確率（どちらも控除を除いて正規化）。
候補（これ以外は試さない。計6通り）:
1. ずれ ≥ 1.3、3連単由来の確率 ≥ 8%、1レース1点（ずれ最大）
2. ずれ ≥ 1.4、同上
3. ずれ ≥ 1.6、同上（今の通知の条件 v9）
4. ずれ ≥ 2.0、同上
5. ずれ ≥ 1.6、3連単由来の確率 ≥ 15%、1レース1点
6. ずれ ≥ 1.6、3連単由来の確率 ≥ 8%、1レース2点まで

注意: 確定オッズで選んで確定払戻で計算するので、締切6分前に選ぶ実運用より甘い（上限の目安）。11/3 の実測では6分前→確定で選んだ目のオッズが中央値0.77倍に下がった。
採用の判断は CLAUDE.md の合格ライン（12か月で回収率>1.0・勝ち月8以上）と、締切前ログでの前向き確認の両方が要る。
