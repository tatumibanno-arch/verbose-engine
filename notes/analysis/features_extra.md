2026-11-03 作成。研究用。**本番の選定（rules.yaml・select_races.py）は何も変えていない。**

- コード: `scripts/features_extra.py`（`build_extra(con, hd_from, hd_to)`。既定の `features.py` の動作は変えず、使うときだけ (hd, jcd, rno, lane) で横付けする）
- 評価: `scripts/analysis/features_extra_eval.py`（`run` / `report`。作業ファイルは scratchpad の `fx/`）
- 作り方: `python scripts/features_extra.py --from 20251101 --to 20261031 --out <path>.parquet`（半年分で約2分）
- リーク検査: `python scripts/features_extra.py --leak-check 20251102,20260610 --workdir <dir>`

## 天候・風・波は見送り（運用者の判断）

当初の候補1（前日の天候、当日の風の上限見積もり）は、**運用者の判断で見送った**。
`races` テーブルの天候・風向・風速・波高は使っていない（コードからも削除済み）。途中で一度だけ天候列入りの版を作ったが、評価する前に取りやめたので数字は無い。
天気予報を取りにいく価値があるか（当日の風の上限）は、今回は測っていない。

## 作った特徴量（全54列）

窓はすべて「レース日 d の前日まで」（features._Hist で d の0時より前だけを集計。当日の前半レースも入らない）。

### S: 今節の調子（sr_、21列）
同じ選手・同じ場で直近7日（`MEET_WINDOW`）の、**前日までの走り**を集計。今節の初日は NaN（全体の約18%）。

| 名前 | 意味 |
|---|---|
| sr_n | 今節これまでの出走数 |
| sr_ex_rank, sr_ex_res, sr_ex_top2 | 展示タイムのレース内順位の平均（1=最速）、レース内平均との差の平均（負が速い）、展示1〜2位の割合 |
| sr_st, sr_st_rank | 今節の平均ST、レース内ST順位の平均 |
| sr_inward | 今節の平均「枠番 − 進入コース」（+ が前付け） |
| sr_last_ex_rank, sr_last_ex_res, sr_last_st | 今節の直近の出走日だけの値 |
| sr_ex_res_vs_365, sr_st_vs_365 | 今節の値 − その選手の365日平均（今節の足・STが普段よりどうか） |
| sr_{ex_res, ex_rank, st}__{dmean, dlane1, rank} | レース内の相対値 |

今節は同じモーターに乗るので、sr_ex_* は「この選手 × このモーター」の今節の足の目安。

### M: モーターの直近（mm_、8列）
同じ場・同じ入れ替え期（features.py のモーター入れ替え検出）の同じモーターの直近30日（前の数節、別の選手が乗った分も含む）。
mm_n, mm_ex_rank, mm_ex_top2, mm_top3, mm_ex_rank_shrunk（(順位合計 + 10×3.5)/(n+10)）とその相対値（__dmean, __dlane1, __rank）。

### C: 進入のクセ（ce_、14列）
| 名前 | 意味 |
|---|---|
| ce_movein180, ce_movein365 | 2〜6号艇のとき、枠より内のコースに入った割合（前付け率） |
| ce_movein_shrunk | 365日の前付け率を全体平均 0.03 へ縮小（仮想20走） |
| ce_pushed180, ce_pushed365 | 枠より外に出された割合 |
| ce_n365 | 365日の進入記録のある出走数（2〜6号艇） |
| ce_outer_max_movein | 自分より外の艇の前付け率の最大（自分のコースを取られる脅威） |
| ce_race_max_movein, ce_race_sum_movein | レース内（2〜6号艇）の前付け率の最大・合計（「前付けする艇がいるか」のレース単位の旗） |
| ce_lane1_keep | 1号艇の選手が1号艇のとき1コースから出た割合（365日、0.97へ縮小） |
| ce_venue_wakunari365 | 場の365日の「全艇が枠なり」だったレースの割合 |
| ce_movein_shrunk__{dmean, dlane1, rank} | レース内の相対値 |

既存の features.py にも rlane_keep / rlane_inward / r_inward_all（この選手がこの枠のとき）はある。今回は「レース内の他艇の前付け」を足したのが新しい点。

### V: 場の直近（vc_、4列）
同じ場の直近3日（前日まで）の1号艇1着率・1号艇の1コース進入率・2コースまでの1着率・平均ST。成績だけから作る（天候は使わない）。

### O: その他（ot_、7列）
| 名前 | 意味 |
|---|---|
| ot_home | 番組表の支部が、その場のある都府県（地元）か |
| ot_st_trend | 直近30日の平均ST − 365日の平均ST（負＝最近早い） |
| ot_runs7, ot_runs30 | 直近7日・30日の出走数 |
| ot_st_vs_inner, ot_st_vs_outer | 自分の365日平均ST − 内隣（外隣）の艇の365日平均ST（負＝隣より早い） |
| ot_inner_sr_ex_res | 内隣の艇の今節展示（sr_ex_res） |

F（フライング）の影響は既存の rs_F・ser_F でもう入っているので足していない。results からは F を見分けられない（ST が正の値で入っている）。

## リークの考え方

| 特徴量 | 使うデータ | 前夜に分かるか |
|---|---|---|
| sr_*, mm_*, ce_*, vc_*, ot_st_*, ot_runs* | results の展示タイム・進入・ST・着順の**レース日より前の日**の分 | 分かる（前日までのレースは終わっている） |
| 相対値（__dmean など）、ce_outer_max_movein、ot_st_vs_* | 上の値を同じレースの番組表の6艇で並べたもの | 分かる（番組表は前夜） |
| ot_home | 番組表の支部 | 分かる |

## 測り方

- モデル: `trifecta.py` の StageModel の**第1段と同じ**（LightGBM 2値・1着、同じパラメータで num_threads=3、レース内 softmax(τ・score)、τ は検証2か月で決める）。
- 基本の特徴量: trifecta.py のキャッシュ（features.py、stats_lag_days=45、180列）。
- ウォークフォワード: 2025-11〜2026-10 の各月を、直前24か月（最後の2か月は早期打ち切りと τ 用）で学習して予測。12か月 × 11構成 = 132回学習。
- 指標: 1着が1艇に決まったレース（55,626レース）での 6艇の対数損失（レース単位、−log P(1着艇)）と、確率最大の艇が1着だった割合。
- 差は同じレースで対にして比べる。SE はレース単位のブートストラップ（300回）。
- **雑音の目安**: 特徴量を変えずに乱数の種だけ変えた base_seed2。

## わかったこと

1. **効いたのは「今節の展示タイム」（S）と「モーターの直近の展示」（M）**。前日までの展示は、前夜に使える情報の中で既存の特徴量（選手の30〜180日、モーター期全体の平均）より新しい足の情報になる。
2. 進入のクセ（C）は単独では小さい（−0.8、7/12か月）。既存の rlane_inward などでほぼ取れている。S と一緒なら少し上乗せ（S 単独 −4.2 → S+C −4.8〜−5.4）。
3. 隣の艇との ST 差（ot_st_vs_inner）は gain では新しい列の中で一番使われるが、O 全体の上乗せは −1.4。既存の r90_avg_st の相対値と重なっている。
4. 場の直近3日のイン逃げ率など（V）は効かない（−0.07、雑音の範囲）。
5. **1着的中率はほとんど変わらない**（+0.1pt）。良くなったのは確率の当てはまり（本命以外の艇の確率の付け方）で、本命の選び方ではない。回収率に効くかは、この確率で買い目を作り直して測らないと分からない。

対数損失 −0.007 の大きさ: base 1.185 の約0.6%。種の違いによる揺れ（±0.4）よりはっきり大きいが、これだけでオッズに対して優位になるとは言えない。

## 何通り試したか

- 特徴量の定義: 54列を1回作っただけ。窓（7日・30日・180/365日）と縮小の強さ（10, 20）は先に決めた値で、結果を見て調整していない。
- 構成: 11（base, base_seed2, S, M, C, V, O, S+C, S+C種2, 全部, 全部種2）× 12か月。
- 天候入りの版は作ったが評価前に取りやめた（上記）。
- これはモデルの当てはまりの比較で、買い方・条件の探索ではない。回収率の主張はしていない。
