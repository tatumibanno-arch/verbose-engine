- 作成: 2026-11-02 / スクリプト: `scripts/analysis/roi_scan.py`（`--out PATH.md` で全表、`--csv PATH.csv` で全セル。1回 約2.5分）
- データ: 唐津(23)/津(09) の取り違えを直して取り込み直した後の DB（2026-11-02 時点）で計算した最終の数字。
- **結論: 前夜に分かる条件だけで、検証用期間（2025-11〜2026-10）に回収率1.0超えが「偶然ではない」と言える条件は見つからなかった。**
  - 全レース買いの基準線で一番高いのは「単勝1号艇」の 0.908（勝ち月 0/12）。
  - 30万セルの総当たりで、発見用で >1.0 だったセルは検証用で回収率の中央値 0.749 まで戻った（何もしないのとほぼ同じ）。
  - 採用の合格ライン（直近12か月で通算 >1.0 かつ勝ち月 8以上）に届き、発見用でも >1.0 だったセルは 7。どれも検証用の95%区間が1.0をまたぎ、30万回試した中の7つなので、**採用候補ではなく「前向き検証の候補」**にとどまる。

## 方法

- **回収率** = 払戻合計 ÷ 購入額合計（1点100円）。払戻テーブルにない買い目は外れ（払戻0）。複勝・拡連複の複数の当たりや同着は全部足す。
- **返還の扱い**: results で position が NULL かつ st_timing も NULL の艇を「欠場」とみなし、その艇を含む買い目は返還扱い（購入額0・払戻0、つまり買わなかったのと同じ）。
  position が NULL でも ST がある艇（F・L・転覆・失格などが区別できない）は**外れ扱い**にした（保守的）。感度として「NULL は全部返還」でも計算したが、差は回収率で +0.005〜0.015（下の表の最右列）。
  3連単の払戻が無いレース（中止・不成立）は除外。欠場艇を含むレースは 2,756、position NULL を含むレースは 9,453。
- **番組表と成績の照合**: 選手番号が一致しないレースは番組表の特徴を使わない（場コード取り違えへの保険）。今回の不一致は0件。
- **期間分割**: 発見用 2023-11-01〜2025-10-31（110,634レース）／検証用 2025-11-01〜2026-10-31（55,604レース）。全レースに番組表あり。
- **評価の主軸は暦月**: 月次回収率＝その月の払戻合計÷購入合計で、>1.0 の月を「勝ち月」と呼ぶ。各セルについて通算回収率・月別回収率・勝ち月数/全月数・月次中央値・最悪月を出した。
  **合格ライン**（`config/rules.yaml` の `adopt_*`、スクリプトはここから読む）＝検証用12か月で通算 >1.0 かつ勝ち月 ≥8。表の「合格」列。
- **条件（前夜に分かるもの）は17特徴**: 場、R、R帯（1-4/5-8/9-12）、種別（予選/予選特/一般/一般特/準優/優勝/ドリーム/選抜特選/愛称戦）、月、季節、平日/土日、1号艇級、1号艇全国勝率帯、1号艇当地勝率帯、1号艇−他艇最高の勝率差、A1の数、勝率1位の艇、外枠(4-6)最高−1号艇の勝率差、1号艇モーター2連率帯、モーター2連率1位の艇、2-6号艇平均勝率帯。
  単独17と2特徴の組134（R×R帯・月×季節は除外）で、切り口は計151通り。
- **買い方は65通り**: 枠ごとの単勝・複勝、2連単 1-2/1-3/1-23/1-全/2-1/BOX123、2連複・拡連複の1軸、3連単 1-2-3/1-23-23/1-234-234/1-2345-2345/1-全-全/1-2-全/1-3-全/1-4-全/BOX123/2-1-全/2〜6号艇頭の流し、3連複 1=2=3/1=2=全/1=全=全/BOX1234、各券種の全通り。
  ほかに番組表で決まる買い目（勝率1位の単複、当地勝率1位、モーター1位の単複、外枠勝率1位の単複と3連単頭、勝率順の2連単/3連単/3連複、1−他艇勝率1位、1−他上位2艇）。
- **閾値**: 発見用で 300レース以上かつ 30的中以上のセルだけを評価し、**301,151 セル**を試した。
- **不確かさ**: z 値はレース単位の比推定（デルタ法）の標準誤差から出した。表の [95%] は**日単位ブロックのブートストラップ**（1000回）。
- **多重比較**: 301,151 セルに Bonferroni（片側 α=0.05/N）をかけると、z>5.10 が必要になる。

## 次に試すべきこと

1. **オッズを使う**。払戻だけでは、「売れていない（配当が高い）のに来やすい」レースを前夜に見分けられない。本命-大穴バイアス（単勝1号艇 0.91、外枠ほど控除が重い）と「1号艇が売れていないとき（B1・当地勝率が低い）ほど単勝1が上がる」傾向は確認できた。次は締切オッズ（取れれば前日オッズ）と、番組表から推定した勝率を比べて、**期待値>1 の買い目だけを買う**形にする。
2. **事前登録して前向き検証**: 江戸川の1号艇（03×1号艇B1 または 当地勝率<5 の単勝1／2連単1-他艇勝率1位）を1本だけ決め、2026-11 以降の暦月で合格ラインを判定する。条件の追加いじりはしない。
3. 番組表の特徴を増やす: 今節成績（series_results）、早見、級別×年齢、F持ちなど。特徴が増えるほど多重比較は厳しくなるので、**発見用をさらに時系列で二分**し（2023-11〜2024-10 で探し、2024-11〜2025-10 で絞る）、検証用は最後に1回だけ見る。
4. スキャンの順位付けを、通算回収率から「勝ち月数」や「月次回収率の下側分位」に変えた版も並べる。高分散の穴が上位に来にくくなる。
5. 返還の精度を上げる: results に F/L/転覆 の区別が入れば、外れ扱いにしている position NULL（約6,700レース）を正しく返還できる。影響は回収率で最大 +0.015 程度。
