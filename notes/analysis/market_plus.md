# 市場から出発する3連単モデル（③ 市場＋α）

2026-11-04 作成。研究用。**本番の選定（rules.yaml・select_races.py）は何も変えていない。**
コード: `scripts/analysis/market_plus.py`。作業ファイルは scratchpad の `trifecta/mp/`（リポジトリには置かない）。DB は読み取り専用。

## 0. 事前の宣言（モデルの当てはまり・買い方の成績を見る前に書いた）

### ねらい
3連単の締切オッズ（いちばん当たる予想）を出発点にして、市場が軽く見ているかもしれない情報で少しだけ動かす。
動かした確率 × オッズ（期待値）で買って 1.0 を超えるかを見る。

### モデル（条件付きロジット、1レース120通りの中で当たりを説明）
score(組 a-b-c) = θ·[log q, (log q)², log P] + Σ_{着 p=1,2,3} β_p · x(p着に置いた艇) ＋ β_1' · x(1着の艇)·[1号艇]
- q: 締切の3連単オッズから出した市場確率（1/オッズ を正規化）。P: 前夜モデル（trifecta.py、OOS）の確率。
- x: 艇ごとの素性（学習月で標準化、欠けは 0）。係数は着順ごとに別（1着・2着・3着で効き方が違う）。1号艇が1着の組だけ別の上乗せ係数。
- 線形・L2 正則化（λ は固定 1.0、調整しない）。LightGBM は使わない（係数が少なく、学習が数か月分でも安定するため）。
- 学習: 対象月より前の、締切オッズのある月すべて（拡大窓）。締切オッズは 2025-11 からなので、
  評価する月は **2026-01〜2026-10（10か月、学習は最低2か月）**。2025-12 は学習1か月の参考として出すだけ。

### 素性のグループ（構成。これ以外は作らない）
| 構成 | 中身 |
|---|---|
| M0 | 市場だけの再校正（log q, (log q)²） |
| M0+P | ＋前夜モデル log P |
| N | M0+P ＋前夜の艇の素性: 全国勝率・当地勝率・コース別1着率（rc_win_shrunk）の レース内差、級、期別/90日の平均ST差、今節の展示（sr_ex_res__dmean）、モーター直近（mm_ex_rank_shrunk__dmean）、隣とのST差（ot_st_vs_inner） |
| E | M0 ＋当日の展示タイム（results.data の exhibition_time。直前情報の展示タイムと 100% 一致を確認済み）: レース内平均との差、レース内順位1位/6位、その選手の今節展示（前日まで）との差 |
| NE | N ＋ E（**買い方の評価に使うのはこれ1本**） |
| NEB（第2段） | NE ＋直前情報（beforeinfo）: スタート展示の進入コース≠枠、スタート展示ST（レース内差）、チルト、部品交換あり、体重（番組表との差）、調整重量 |

### いつ分かる情報か（締切15分前ごろに買う前提）
| 素性 | 分かる時点 | 使えるか |
|---|---|---|
| 締切オッズ q | 締切時 | **買う時点では分からない**（締切数分前のオッズで代わりにする。確定と違う） |
| 前夜モデル P、前夜の艇の素性 | 前夜 | 使える |
| 展示タイム | 展示後（締切の約20分前） | 使える（results.data の値は直前情報と同じ値。確認: 2026-10 の 17,970 艇で 100% 一致） |
| results の進入コース・ST・着順 | レース後 | **使わない**（進入は直前情報と 95.6% しか一致せず、ST は 2.6% しか一致しない＝本番の値） |
| 直前情報（スタート展示の進入・ST、チルト、部品、体重） | 展示後 | 使える（第2段、beforeinfo） |

## 結論（先に）

- **市場を出発点にすると、確率の当てはまりは確かに良くなる**: 3連単の対数損失 素の締切市場 3.6748 → 調整後（NE）3.6622（−12.7×10⁻³、SE 0.8、10/10か月で改善）。2連単（集計）2.4593 → 2.4503、1着 1.1394 → 1.1339。
- 効いているのは**前夜の情報**（前夜モデル log P と艇の素性）。**当日の展示タイムは、前夜の素性を入れた後ではほぼ何も足さない**（NE−N = −0.01×10⁻³）。直前情報（スタート展示の進入・ST、チルト、部品交換、体重）も足すと**かえって悪くなった**（+1〜3×10⁻³、今あるのは3か月の各20日分だけ）。締切の市場は展示・直前情報をもう織り込んでいる。
- **それでも買うと 1.0 に届かない**（締切オッズで選んで締切オッズで払う、甘い計算でも）。事前に決めた9本の10か月の回収率は 0.52〜1.28。発見用で一番良かった R8（1-x-y の EV 最大1点、発見 1.540）は検証 0.694。的中の多い中で発見用最良の R9（2連単 EV 最大1点、発見 1.059）は検証 0.936。
- 調整後の確率と市場の比で全部の目を並べると、比が大きい目ほど回収率が上がる（0.51 → 0.88）。**向きは正しいが、一番上の帯でも 0.88**。控除率約25% を越えるほどの差は無い。
- 運用者の型（SG/G1 相当・イン逃げ・1-x-y・合成オッズで配分）は R4/R5 で、条件に合う日が少なすぎて（1日0.3〜0.5レース、10か月で的中5〜10本）判断できない。全グレードに広げた R6/R7 は 0.72〜0.78。

## 1. 作り方

- データ: 3連単の締切オッズが全120通りそろい、結果のあるレース 55,037（2025-11〜2026-10）。評価は 2026-01〜10 の 46,437 レース。
- 学習: 対象月より前の全月（拡大窓、2025-11〜）。条件付きロジット（scipy L-BFGS、L2 λ=1、係数 最大 3+13×4=55 個）。1か月の学習は約20秒。
- 艇の素性は `trifecta/feat`（features.py）と `fx/extra_*`（features_extra.py、S・M・O）から。標準化は学習月の平均・標準偏差で。
- 展示タイムは results.data の exhibition_time（6.0〜7.5 秒の外は欠け扱い）。

- 締切市場自体を素性に使っているので、締切前の運用にそのまま持ち込めない（6分前のオッズで同じモデルを学習し直す必要がある。今は締切前オッズの過去データが無い）。

## 5. 何通り試したか
- 当てはまりの構成: 5（M0, M0P, N, E, NE）× 11か月、第2段 2 構成（NEB、小さい版）× 2 通りの学習。λ・素性・切り方は先に決めた値のまま（調整なし）。

## 6. 結論
- **市場から出発して前夜の情報で動かすと、3連単の当てはまりは市場より確かに良くなる**（10/10か月、−0.34%）。前夜モデル単独（市場に大きく負ける）とは違い、市場の上に小さく上乗せはできる。
- しかし**その差は控除率（約25%）を越えるには小さすぎる**。締切オッズで選んで締切で払う甘い計算でも、事前に決めた買い方は検証で全部 1.0 未満（0.68〜0.94、件数の少ない R4 を除く）。合格ライン（12か月 >1.0・勝ち月8）にはどれも遠い。
- 展示タイム・直前情報は、市場がもう値段に入れている。**直前の情報で市場を上回る余地は、データで見える範囲では見つからなかった**。運用者が勝っているなら、ここで測っていないもの（実際の足の見え方、オッズの動きの読み）か、偶然の可能性が高い。運用者の実際の買い目と成績を記録して比べるのが次の手。
- 本番・紙上の採用候補にはしない。rules.yaml・本番の選定は変えていない。
