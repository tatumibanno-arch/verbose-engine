2026-11-02。点検対象は `notes/analysis/trifecta.md` の単勝の節、`scripts/analysis/trifecta.py`（tansho / odds）、`scripts/features.py`。

## 結論（先に）

- **リーク（レース結果の混入）は見つからなかった。かなり確か。** 根拠は下の「確かめたこと」の 1〜5。
- **「モデルが締切単勝オッズに勝つ」（対数損失 1.184 対 1.239）と「締切オッズ×確率≥1.2 で 1.29」は、リークのせいではない。単勝の売り場が小さくて、締切オッズが雑音だらけなのが原因。** ただし trifecta.md の書き方（「上限の参考」「単勝の市場はモデルより当たっていない」）は誤解を招くので、直したほうがよい（下の問題 A・B）。
  - モデルを使わず「締切オッズと枠番だけ」で作った確率で選んでも、同じ期間の回収率は 1.26 になる。
  - 同じ日（2026-11-01、166レース）では、**3連単オッズから出した1着確率（対数損失 1.113）がモデル（1.130）にも単勝オッズ（1.222）にも勝つ**。深い売り場にはモデルは勝てていない。モデルが結果を覗いているなら、ここでも勝つはず。
- **本番候補「1着確率≥20% かつ 確率×予想単勝配当≥1.0」（前夜の情報だけ）**: 再計算で発見用 1.017・検証用 1.012 を完全に再現できた。リークは無い。ただし **1.0 を超えているとは統計的に言えない**（24か月で 1.0145、日単位ブートストラップの90%区間 0.995〜1.035）。しかも25候補から、2期間の両方を見て選んだもの。
  - **紙上運用（paper）に進めるのは良い。** お金はかからず、前向きの確認そのものなので。ただし本番（実際のお金）は前向きの記録を見てから。条件は下の「紙上運用の条件」に書いた。

## 確かめたこと

### 1. 番組表の今節成績（series_results）に当日の結果が入っていないか → 入っていない
- 2026-02〜10 の番組表で、同じ選手・同じ場の連続した2日（127,877組）を比べた。d+1 日の文字列は**100%**「d 日の文字列＋d 日に走った分」になっている。
  - d 日に1走: 51,036組が +1 文字。d 日に2走: 75,334組が +2 文字。
  - 「d 日の文字列にもう d 日の結果が入っている」（増え方0）は約1,000組だけ。中止・欠場の日と同じくらいの数で、パターンも合う。
- 1日に2走する選手（95,391人日）で、1走目と2走目の文字列が違うケースは**0件**。1日の途中で書き換わっていない。
- 例: 住之江 2026-07-15 の木下翔太は ''（初日）。07-16 は '22'（07-15 の2着・2着）。

### 2. 同じ日の前のレースの結果を特徴量が持っていないか → 持っていない
2025-11〜2026-10 の 55,626 レースで、条件付きロジットに「モデルの log P1」と「同じ選手の、同じ日・前のレースの着順」を入れた。
- 前のレースの着順の係数は −0.061（標準誤差 0.006）。1着なら +0.151（標準誤差 0.024）。
- つまりモデルに足すと**情報が増える**（対数損失 1.1849 → 1.1840）。モデルがすでに当日の結果を持っているなら、増えないはず。

### 3. 特徴量のリーク検査（切り詰めDBとの一致）
features.md の検査の作りは正しい（entries は D 以前、results・payouts・racer_stats は D より前）。
- 単勝オッズのある期間の2日（2026-06-20, 2026-08-26）で、trifecta と同じ `stats_lag_days=45` を使って再実行した。結果は下の追記を参照。
- racer_stats.hd は算出期間の最終日。lag 45 日で使っているので、結果の先取りにはならない。公開日の厳密さの問題だけが残る（features.md の注意2）。

### 4. ウォークフォワードの境界 → 問題なし
- 着順モデル: 予測月 m の学習は [m−24, m−2)、早期打ち切りと τ・λ は [m−2, m)。四半期ごとの学習（PRE_FITS）も、予測するのはその後の3か月だけ。
- `recalibrate`（P^α）: α はその月より前の月だけで決めている（結果は全部 α≈1.0）。
- 単勝の推定配当 G1: 月 m の学習データは `G_FIRST_MONTH ≤ 月 < m` の当たりだけ。入力（P1、全国勝率、級別、場、R、レース種別）は全部前夜の情報。
  - 学習と予測の間を1か月空けても、発見用 1.022・検証用 1.018 で変わらない。
- 損失の計算・閾値選びに評価月は使っていない。ただし**候補（25本）の中から本命を選ぶときは、発見用と検証用の両方を見ている**（trifecta.md にもそう書いてある）。

### 5. ラベル・結合
- 単勝の勝ち艇は払戻表から取っている。results の1着と突き合わせると、2026-02〜10 の全レースで食い違いは0。同着も無い。
- 唐津/津: features の venue_fix は履歴集計のキーにしか使っていない。単勝の評価は entries の (hd, jcd, rno) と払戻表の結合だけ。津に唐津の払戻が混ざる日は、唐津の行が entries 側に無いので落ちる。ラベルのずれは見つからなかった。

## 見つけた問題と影響

### A. 市場確率の作り方が不公平（「モデルが市場に勝つ」の大きさを誇張）【中】
1/オッズを比例で正規化しているので、単勝の売り場の強い偏り（人気薄の過大評価・1号艇の過小評価）がそのまま残る。
- 2026-03〜10・36,172 レースの枠別の平均: 1号艇は市場 0.473・実際 0.547。6号艇は市場 0.052・実際 0.029。
- オッズと枠番だけで市場を校正した（log オッズ×枠＋枠の定数、前の月で学習）。それでも市場の対数損失は 1.238 → 1.217 までしか下がらず、モデル（1.183）にはまだ負ける。
- 単勝市場は、番組表の全国勝率さえ取り込み切れていない。校正済みの市場に全国勝率の相対値を1つ足すだけで、対数損失が 0.021 下がる。
  - ほかに足して効く特徴量: 期別勝率 0.017、直近90日1着率 0.017、コース別1着率 0.017。モーター系は 0.003 程度。
  - **モデルの優位は、特別な特徴量ではなく、いちばん基本的な公開情報から来ている。** リークではなく、単勝の売り場の質の問題。

### B. 「締切オッズで選ぶ ＝ 上限の参考 1.29」は実現できる数字ではない【大（解釈）】
単勝の売り場はとても小さく、締切オッズが雑音だらけ。

| 現象 | 数字（2026-03〜10） |
|---|---|
| 1.0倍（元返し）の艇がいるレース | 13.5%（4,919 レース） |
| その1.0倍の艇の勝率 | 73.6%（公平なオッズなら約1.36倍） |
| 単勝が1枚も売れていない艇（オッズ 0.0）がいるレース | 5.5% |

- 1艇に大口が入るとほかの艇のオッズが跳ね上がり、締切オッズで見ると「期待値>1」の艇が大量に出る。
- モデルを使わず「締切オッズ×枠」で校正しただけの確率で選んでも、回収率は 1.26（EV≥1.0、8,961点、7か月すべて 1.13〜1.43）。
- 枠×オッズ帯で見ると、1号艇の5〜10倍は 1.32、10〜20倍は 2.60。2〜4号艇の50倍超は 1.5〜1.9。
- モデルの「締切×確率≥1.2」（27,114点・1.291）の利益の**60%**は、最低オッズ≤1.1倍のレース（全体の24%）から来ている。その部分の回収率は 1.62、それ以外は 1.10〜1.17。
- 確定オッズは締切後の最後の大口まで含んだ値なので、買う時点では分からない。売り場が小さいので、自分の100円でもオッズが動く。
  - **したがって「上限」ではなく「後知恵の参考」。** 運用を締切前の購入に変えても、この数字は期待できない。

### C. 単勝の払戻が無いレースを落としている（特払い）【小】
- オッズ 0.0（売れていない）の艇が1着になると、払戻表に単勝の行が無い。2026-02〜10 で25レース。これらは `has` で評価から落ちる。
- 締切オッズ版では、その25レースの買い目が全部外れなのに数えられていない。点数の0.1%未満なので、影響は無視できる。
- 対数損失の比較でも同じ25レースが落ちている（市場の分母が∞になるはずのレース）。

### D. F（フライング）・出遅れの艇を「外れ」扱い【小・保守側】
- 実際の規則では F・L の艇の舟券は返還。コードでは「ST があって着が無い」艇（F・転覆・失格を区別できない）を外れにしている。
- 全部を返還扱いにすると、本番候補は 1.017→1.023（発見用）、1.012→1.017（検証用）。少しだけ悲観側の数え方で、結論は変わらない。

### E. 本番候補（予想オッズ版）の強さ【統計】

| 確かめたこと | 発見用 | 検証用 |
|---|---|---|
| 再現 | 1.017 (8/12) | 1.012 (8/12) |
| 参考: 確率≥20% を全部買う | 0.911 | 0.907 |
| 近くのしきい値: EV≥1.0・p≥0.15 | 1.031 | 1.036 |
| 近くのしきい値: EV≥0.97・p≥0.2 | 0.994 | 0.990 |
| 近くのしきい値: EV≥1.05・p≥0.2 | 1.020 | 1.054 |

- 期待値で絞ると、0.91 → 1.0前後まで上がる効果は2期間で安定している。
- 1.0 を超えるかどうかは、しきい値を少し変えるだけで変わる（勝ち月 1〜9/12）。
- 日単位ブートストラップ（2,000回）:
  - 検証用: 1.0125、90%区間 0.988〜1.037、P(>1)=0.80
  - 24か月: 1.0145、90%区間 0.995〜1.035、P(>1)=0.89
  - 25候補から選んだことを考えると、もっと弱い。
- 枠別（検証用）: 1号艇 1.014（6,007点、10/12）が中心。2号艇は 0.93、4号艇は 1.07 とばらつく。
- 締切オッズのある期間で、この候補の買い目を見た:
  - 最低オッズ≤1.1倍のレースでは 0.892。大口が自分の艇に入ると、配当が1.0倍につぶれる。
  - それ以外のレースでは 1.053。

## 紙上運用（予想オッズ版の単勝）の判断

**リークは無いので、紙上運用に進めてよい。** ただし「1.0を超える証拠がある」とは書かないこと。期待は「控除25%の売り場で、ほぼ損益分岐」。進める条件:
1. ルールを固定して前向きに記録する: P1≥0.20 かつ P1×G1/100≥1.0。モデルと G1 は毎月学習し直し、欠場は返還、1点100円。しきい値は途中で変えない。
2. 判定の目安: 3か月で約2,000点、通算>1.0、勝ち月2/3以上。それでも区間は ±4% 程度ある。本番（お金）に移すのは6か月分を見てから。`min_sample_races` の約束にも合う。
3. 同じ日の締切単勝オッズも記録する（scrape_web の oddstf）。「自分の艇が1.0倍になった割合」と「その日の回収率」を一緒に見る。大口でつぶれるレースが多いなら、「前夜に人気が集中しそうなレース（予想1番人気の P1 が大きい）を外す」案を発見用で検討する。
4. F・L の返還を正しく数える（問題 D）。
